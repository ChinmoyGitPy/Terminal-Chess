**The executable is available in the dist folder...**

**As the name suggests, you can intitutively understand it's basically a chess that can be played in the terminal :) I've implemented all complex logic like castling, en passant, pawn promotion etc. I used lowercase letters to indicate black pieces and uppercase letters for white pieces.** 
![image](https://cdn.hackclub.com/019eae21-ea6c-7dfd-9d52-e0b01ec185ff/Screenshot%202026-06-10%20020800.png)

**I used Python 3.12 which is highly stable but any newer version is supported and no prerequisitic dependencies are required. Honestly it's a very good exercise project and tests the caliber of python programmers, so I'd definetely suggest programmers especially game-dev, to give this a try. The functions, main game loop and legal system all in overall is quite harder than it sounds, making it a tough problem to crack.**
